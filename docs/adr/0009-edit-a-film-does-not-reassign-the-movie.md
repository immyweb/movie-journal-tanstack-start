# Edit a film does not allow reassigning the Movie

Editing a JournalEntry (`/journal/{entryId}/edit`) updates only `dateWatched`, `rating`, `review`, and `like` — there is no TMDB re-search and no way to point the entry at a different Movie. This matches `docs/SYSTEM-DESIGN.md`'s original `/edit-movie/{id}` spec, which never accepted `theMovieDbId` as a parameter (only the mutable fields ADR 0001 later split out into JournalEntry), and it keeps the form's `LogFilmForm` movie panel a static summary rather than a second TMDB search flow. A user who logged the wrong film has no in-app fix for that today — they'd need to delete and re-log — which is a real cost worth naming rather than leaving implicit, since a reader hitting that limitation would otherwise wonder whether it was an oversight.
